# 보안사고 경위서

1. 개요: 2026. 2. 6. 제8015항공대대 정비중대 제1통제구역에서 비밀문서 관리 소홀 사례가 발생하였다.

2. 관련자: 제8015항공대대 정비중대 염정우 이병

3. 경위: 염정우 이병은 제1통제구역에서 정보수집 계획을 취급한 뒤 보관함에 넣지 않고 책상 위에 둔 채 자리를 비웠다. 순찰 중이던 간부가 이를 발견하여 즉시 회수하였다.

4. 위반 규정: 비밀문서 관리 규정상 퇴실 시 비밀 보관 의무를 지키지 않았다.

5. 조치: 비밀관리책임자 중위 배윤호가 염 이병을 대상으로 비밀 취급 절차 재교육을 실시한다.
