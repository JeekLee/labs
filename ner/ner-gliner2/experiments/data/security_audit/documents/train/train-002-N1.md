# 보안사고 경위서

1. 사고 개요: 제6008공병단 정보과에서 비밀문서 관리 소홀 사례가 확인되었다.

2. 관련자: 제6008공병단 정보과 옥민규 일병.

3. 사고 경위: 옥민규 일병은 2026-09-12 전산실에서 암호운용 지침을 열람한 뒤 보관함에 반납하지 않고 책상 위에 둔 채 자리를 비웠다. 순찰 중이던 비밀관리책임자 주민성 상사가 이를 발견하여 회수하였다.

4. 위반 규정: 열람 후 즉시 보관하도록 정한 비밀문서 관리 규정을 지키지 않았다.

5. 조치: 옥 일병에 대해 비밀문서 취급 절차 재교육을 실시할 예정이다.
