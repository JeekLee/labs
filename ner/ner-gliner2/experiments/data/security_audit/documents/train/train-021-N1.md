# 보안사고 경위서

1. 개요: 2026. 9. 19. 제7022통신단 운영과 제1통제구역에 설치된 업무단말-43의 사용자 계정이 다른 인원에게 넘겨져 사용된 사실이 드러났다.

2. 관련자: 제7022통신단 운영과 양민서 상병(단말 취급자). 계정 발급과 말소는 정보체계 관리자 명지우 중사가 담당한다.

3. 경위: 양민서 상병은 업무단말-43의 취급자로 등록되어 있었으나, 근무 교대 시 자신의 계정 정보(****)를 후임에게 알려 주어 대신 접속하게 하였다. 같은 날 단말에는 HDD-385가 연결된 기록도 남아 있었다.

4. 위반 규정: 개인 계정의 양도와 공동 사용을 금지한 정보체계 계정 관리 지침을 어겼다.

5. 조치: 명지우 중사가 2026. 12. 31.까지 해당 단말 계정을 말소하고 접근 권한을 다시 부여한다.
