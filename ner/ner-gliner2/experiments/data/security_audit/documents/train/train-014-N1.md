# 보안사고 경위서

1. 사고 개요: 2026-08-07 제4027기계화여단 본부중대 제1통제구역에서 비밀문서 통신망 구성도가 보관함 밖에 방치된 채 발견되었다. 이는 비밀문서 관리 소홀 사안에 해당한다.

2. 관련자: 통신망 구성도를 마지막으로 대출한 사람은 제4027기계화여단 본부중대 반승현 이병이며, 통신망 구성도의 보관 책임자는 비밀관리책임자 소지훈 소령이다.

3. 경위: 반승현 이병은 업무 협조를 이유로 통신망 구성도를 열람한 뒤 반납 절차를 밟지 않고 책상 위에 둔 채 자리를 비웠다. 순찰 중이던 간부가 이를 발견해 즉시 회수하였다.

4. 위반 규정: 열람 후 즉시 반납과 보관함 시건을 규정한 비밀문서 관리 규정을 지키지 않았다.

5. 조치: 소지훈 소령이 2026. 12. 31.까지 관련 인원을 대상으로 비밀문서 취급 재교육을 실시한다.
