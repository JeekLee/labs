# 보안사고 경위서

□ 개요: 제6008공병단 정보과에서 본인에게 부여되지 않은 접속 권한으로 단말을 사용한 사실이 확인됨.

□ 관련자: 제6008공병단 정보과 소속 이병 조수아

□ 경위: 이병 조수아는 2026. 3. 24. 통신기계실에서 다른 사람에게 발급된 계정으로 로그인한 뒤 HDD-215를 연결하여 작업하였다. 접속 기록 점검 과정에서 계정 사용자와 실제 사용자가 다르다는 점이 드러났다.

□ 위반 규정: 계정은 발급받은 본인만 사용하도록 한 정보체계 계정 관리 지침을 어김.

□ 조치: 정보체계 관리자 곽지환 소위가 조 이병의 접속 권한을 회수하기로 함.
