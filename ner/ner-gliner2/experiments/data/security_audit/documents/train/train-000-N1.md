# 보안사고 경위서

1. 사고 개요: 제9013보병사단 작전처에서 저장매체 무단 반출 사고가 발생하였다. 승인되지 않은 이동식 저장매체 USB-374가 부대 밖으로 반출된 사실이 매체 수량 확인 과정에서 드러났다.

2. 관련자: 제9013보병사단 작전처 소속 일병 길하율. 보고자는 정보보호 담당관 황하율 중사이다.

3. 경위: 길 일병은 2026. 11. 28. 문서보관실에서 업무용으로 사용하던 USB-374를 반출 승인 절차 없이 개인 소지품에 넣어 퇴근하였다. 다음 날 매체 수량 확인 중 USB-374가 비어 있는 것이 확인되어 경위를 조사하였다.

4. 위반 규정: 본 행위는 저장매체 통제 지침에서 정한 반출 승인 절차를 지키지 않은 것이다.

5. 조치: 정보보호 담당관 황하율 중사는 해당 매체를 즉시 회수하고 길 일병에 대한 추가 조사를 진행 중이다.
