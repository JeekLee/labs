# 보안사고 경위서

1. 개요: 제6008공병단 인사과에서 접속 권한이 없는 인원이 공용 단말에 로그인하여 매체를 사용한 사실이 확인되었다.

2. 관련자: 제6008공병단 인사과 공수호 이병

3. 경위: 공수호 이병은 2026-08-14 작전회의실에서 선임에게 발급된 계정 정보를 넘겨받아 로그인하고 USB-124를 연결하였다. 체계 접속 기록에서 권한 범위를 벗어난 사용이 탐지되어 확인하였다.

4. 위반 규정: 정보체계 계정 관리 지침은 계정 정보의 공유와 양도를 금지하고 있다.

5. 조치: 정보체계 관리자 문유찬 상사가 해당 계정과 공 이병의 접속 권한을 회수하였다.
