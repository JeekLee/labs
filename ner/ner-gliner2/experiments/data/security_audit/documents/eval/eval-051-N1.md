# 보안사고 경위서

보고: 제2068기갑여단 통신중대 정보체계 관리자 명진우 대위

위반 규정: 정보시스템 보안 운용 규정

사실관계: 2026.10.21. 보안자재실에서 제2068기갑여단 통신중대 진도윤 일병이 퇴직·전출자용으로 남아 있던 관리자 권한을 이용해 단말에 접속함. 접속 중 외장매체 EXT-745를 연결함.

확인 경로: 주간 접속 로그 검토 중 명 대위가 비정상 권한 사용 탐지. 진 일병은 업무 편의를 위해 사용했다고 진술함.

조치 계획: 진 일병 보유 권한 전면 회수, 담당 명 대위, 기한 2026. 12. 31.
