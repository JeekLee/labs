# 보안사고 경위서

◇ 사고 유형: 비인가 출입 / 발생일 2026-08-09 / 장소 보안자재실

◇ 관련자: 제6008공병단 정보과 병장 편유찬. 해당 구역 출입 인가 없음.

◇ 경위: 편 병장이 입회자 없이 보안자재실에 들어감. 출입 기록상 퇴청 시간 미기재. 출입통제 담당관 7급 군무원 전서윤이 기록 확인 중 인지함.

◇ 위반 규정: 보호구역 관리 규정.

◇ 조치: 보안자재실 출입통제 설비 보완. 담당 7급 군무원 전서윤, 기한 2026. 12. 31.
