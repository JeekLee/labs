# 보안사고 경위서

1. 개요: 제7022통신단 운영과 명예준 상병이 비밀취급인가 만료 상태로 서버실에서 부대배치 현황을 열람함. 사건 유형은 인가 만료자 접근임.

2. 관련자: 명예준 상병. 인가번호 제2026-284호 보유자이나 사고 당시 인가 효력 없었음.

3. 경위: 2026-02-06 명 상병이 서버실 출입 후 부대배치 현황 열람. 인가 유효 여부 확인 없이 열람이 진행됨. 반출 사실은 확인되지 않음.

4. 위반 규정: 비밀취급인가 관리 규정. 만료된 인가로 비밀에 접근한 행위가 해당됨.

5. 조치: 명 상병의 비밀 열람 권한 회수 예정. 담당 보안담당관 곽준우 소령, 기한 2026. 12. 31.

작성: 제7022통신단 운영과 보안담당관 곽준우 소령
