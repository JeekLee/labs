저장매체 반출입 대장 확인 기록 (제6008공병단 인사과, 2026년 7월분)

1. 확인자: 보안담당관 정도현 상사

2. 확인 범위: 인가 만료자인 이태윤 병장이 Ⅱ급 비밀 부대배치 현황 열람 전후로 저장매체를 반출입하였는지 대장을 확인함.

3. 확인 결과: 해당 기간 반출입 신청 및 승인 기록 없음. 대장 정정 흔적 없음.

4. 비고: 대장은 정 상사가 보관하며, 확인 결과를 경위서에 첨부함.
