출입기록 점검 결과 (제1통제구역, 점검 기간: 2026. 4. 20. ~ 4. 30.)

1. 시설 관리자: 제9013보병사단 작전처 보안담당관 조은우 대위

2. 점검 목적: 보안교육 미이수자가 제1통제구역 근무에 투입되었는지 여부를 확인한다.

3. 점검 결과: 2026. 4. 25. 교육 미이수가 확인된 박주원 상병은 근무 투입이 보류되었으며, 점검 기간 중 해당 인원의 출입 기록은 없음.

4. 의견: 출입 인가 부여 시 교육 이수 여부를 사전 확인하도록 조 대위에게 권고함.
